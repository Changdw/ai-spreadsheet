快速上手

用自带的预算表走一遍从 AI 草稿到 Excel 的流程。以下命令在源码仓库根目录执行。

准备并打开

安装 Node.js 24 和 npm 后运行下列命令。Windows 便携版已包含运行环境，解压后双击 AIB.exe 即可。

让模型读取需要的范围

context 给出两个 schema、能力、合成示例，以及指定工作簿的表名、ID、尺寸和版本哈希。read 单独取目标单元格。预算的 D5 应为 14100。

审核改动

示例操作把预算表 C3 的单价改为 2000。draft 返回 data.id。将第二段命令中的 DRAFT_ID 替换为该值，核对差异后应用。

验证并导出

D5 现在应为 15100。workbench 中点击「同步」读取 CLI 的改动。导出的 HTML 可双击查看。重复操作请使用新的导出文件名。
