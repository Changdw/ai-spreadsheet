安装环境

便携包适合使用工作台。从源码开发和打包需要完整工具链。

运行条件

平台 安装环境
Windows x64 便携 ZIP 自带 Node。解压到可写目录，运行 AIB.exe。Install.ps1 注册当前用户的 .aib 打开方式。默认应用由用户选择。
macOS arm64 应用包需在 Apple Silicon 上构建；签名为 ad-hoc，尚未经 Apple 公证。在 Finder 的「打开方式」选择 AIB。要设为默认，在「显示简介 → 打开方式」选择 AIB，再点「全部更改」。
Linux 源码版 Node.js 24、npm、浏览器。原生文件窗口使用 zenity，默认浏览器通过 xdg-open 启动。
开发 Node.js 24.x + 配套 npm，按 lockfile 安装。首次安装需要 npm registry 和 SheetJS 的 CDN，之后离线 CLI 读取本地文件。

安装与卸载

在解压目录运行安装脚本，目标为当前用户 LocalAppData/Programs/AIB/0.1.0。在工作簿的「打开方式」中选 AIB.exe。要用 AIB 双击打开，请选「始终」。其他软件也使用 .aib 后缀，请先确认文件是 AIB JSON 工作簿。 卸载从安装目录运行 Uninstall.ps1。可在任意目录用完整路径调用 aib.cmd。

浏览器测试

Windows 测试使用 Edge，其他平台使用 Playwright Chromium。先构建，再运行完整检查。浏览器测试使用独立临时目录。

制作本地发行包

Windows 需要 x64 Node 24、Windows PowerShell、.NET Framework 4.x 的 csc.exe 及匹配运行时的 LICENSE。默认在 node.exe 旁查找，也可用 AIB_NODE_LICENSE 指定。macOS 需要 Swift / Xcode 命令行工具、codesign、ditto 和同版 arm64 Node 的 LICENSE。

默认产物在 release/，AIB_RELEASE_DIR 可更改位置。每次打包都从干净的临时目录生成 ZIP。已有展开目录供当前使用者继续工作，获取新版请在新目录解压最新 ZIP。Mac 构建应在 Mac 上验证 Finder 打开。

诊断

CLI 找不到浏览器时先检查 build 产物。Windows 的 AIB.Browser.exe 与 cli.cjs 在同一目录。打开工作台请使用 open 获取会话。遇到端口或版本问题，先保存网页编辑，再运行 status、stop，然后重新 open。
