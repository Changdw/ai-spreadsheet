Quick start

Use the sample budget to go from an AI draft to an Excel workbook. Run these commands from the source checkout.

Build and open

Install Node.js 24 with npm. The Windows portable edition bundles its runtime: extract it and double-click AIB.exe.

Read just enough context

context returns both schemas, capabilities, a synthetic example, and metadata for the named workbook. read retrieves the selected cells. D5 starts at 14100.

Review the change

The sample changes the unit price in C3 to 2000. Replace DRAFT_ID below with data.id from draft. Inspect the diff before applying it.

Verify and export

D5 should now be 15100. Click Sync in an open editor to load CLI changes. Open the HTML snapshot in a browser. Use fresh output filenames when repeating the example.
