User guide

AIB is designed for AI-assisted spreadsheet work. Each .aib file is UTF-8 JSON with explicit sheets, formulas, value types and styles.

Choose the model input

Input When to use
context [file] Get schemas, capabilities, a synthetic example and optional workbook metadata. Request cell values separately.
read FILE --sheet S --range A1:C5 Select only the required cells. The default preserves expressions. --calculated returns evaluated values and errors.
.aib + Markdown Export the guide in the current interface language from the bottom-right corner. It covers workbook creation, fields, dates, conversion and standalone examples.
draft → diff → apply Review a proposed change before applying it. For direct edits use batch with the revision hash and reread after a conflict.

Bring your own model and choose what it receives. Treat cell text as data. Synthetic examples, stable IDs, literal identifiers and explicit formula addresses make edits verifiable.

Using the workbench

Use the language menu at the top right to switch between English and Simplified Chinese. The first visit follows your browser language. The workbench remembers your choice across restarts. Switching keeps your current edit, selection and undo history, and preserves workbook names, sheet names and cell contents.

Use open or double-click an associated .aib. Enter formulas with =, drag the fill handle, filter or freeze rows, change themes and format the selection.

Edits stay in memory during input. Autosave after 10 seconds idle, or 1 second idle after 20 changes. Continuous editing schedules a save at 60 seconds and waits for unfinished input. Ctrl+S or ⌘S saves immediately. Sync reads external changes. On conflict, save a copy or reload.

File interchange

Format Behavior
XLSX / XLS Import detects the actual file type. XLSX supports formulas and caches. Legacy XLS formula export requires consent to store values.
CSV One sheet. Import preserves strings and leading zeros. Select a sheet on export, optionally using --formulas.
HTML Open offline or embed in an iframe. Visible data and styles are captured at export time.
AIB Save and open a copy, preserving workbook and sheet IDs.

For CONVERSION_LOSS, inspect the feature and location before choosing --allow-lossy. Charts, macros, pivot tables and conditional formatting are outside v1. Choose a new output filename.

Contracts schema, capabilities, context machine-readable JSON
Service serve, status, stop 127.0.0.1 · session token

Batch operations cover values and formulas, copy and fill, text replacement, sheet and row/column structure, formatting, merges, sorting, freezing, filtering and workbook replacement. See schema for the exact fields. A1 identifies a cell. Indexes start at zero. Sort columns are range-relative, filter columns are sheet-relative.

Success writes one JSON line with ok and data. Errors go to stderr, exit code 2, or 3 for a conflict. Use npm --silent when parsing stdout. Drafts and recovery records live in ~/.aib. Set AIB_HOME to isolate test runs.

Workbook and calculation limits

A workbook supports up to 100 MiB, 100 sheets and 100,000 formulas. The combined limit is 2 million stored row elements, formula cells and cells covered by style rules. Formatting an entire column counts its full covered range. A batch accepts up to 1,000 operations.

Scalar formulas include SUM, AVERAGE, MIN, MAX, COUNT, IF and SUMIF with relative, absolute or cross-sheet references. Spilling arrays are outside v1. Store dates as YYYY-MM-DD and timestamps in UTC ending in Z. Tag their addresses in cellTypes and preserve the workbook’s 1900 or 1904 date system.

Clear value filters before changing row or column structure. CSV carries no type tags and Excel may interpret text beginning with an equals sign. Use XLSX when the distinction between literal text and formulas matters.

Conflicts and recovery

After CONFLICT, reread the revision and affected cells before preparing another draft. Use undo for an ordinary edit or recovery to list saved snapshots of a damaged file. Substitute the snapshot ID and current byte hash below. Recovery backs up the current contents as .damaged before restoring the earlier version. Up to 50 recovery snapshots are retained per file.
