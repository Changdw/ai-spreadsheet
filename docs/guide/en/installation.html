Installation

Choose a portable package to use the workbench, or the source toolchain to develop and build it.

Runtime requirements

Platform Environment
Windows x64 The portable ZIP includes Node. Extract to a writable folder and run AIB.exe. Install.ps1 adds AIB to the current user’s Open with menu. The user chooses the default.
macOS arm64 Build the app on Apple Silicon. The supplied packaging uses an ad-hoc signature without Apple notarization. In Finder, choose AIB under Open With. To make it the default, open Get Info, select AIB under Open With, then click Change All.
Linux / source Use Node.js 24, npm and a browser. Native dialogs require zenity and opening the default browser uses xdg-open.
Development Use Node.js 24.x and its npm, installing from the lockfile. Initial setup uses the npm registry and SheetJS CDN. Offline CLI commands then use local files.

Windows installation and removal

Run the installer inside the extracted directory. It installs to the current user’s LocalAppData/Programs/AIB/0.1.0. Select AIB.exe under Open with. Choose Always to open workbooks in AIB by double-clicking. Other applications also use the .aib extension, so first confirm the file is an AIB JSON workbook. Run Uninstall.ps1 from the installed directory. Invoke aib.cmd by its full path from other folders.

Browser tests

Windows tests use installed Edge. Install Playwright Chromium on other systems before running checks. Browser tests use isolated temporary directories.

Build a local release

Windows requires x64 Node 24, Windows PowerShell, the .NET Framework 4.x C# compiler and the matching runtime LICENSE, next to node.exe or at AIB_NODE_LICENSE. macOS requires Swift / Xcode command-line tools, codesign, ditto and the license of the matching arm64 Node distribution.

Archives are written to release/ or AIB_RELEASE_DIR. Every archive is built from a fresh staging directory. Existing expanded directories are preserved. Extract the new ZIP into a fresh folder to use it. Verify Finder opening on a Mac.

Troubleshooting

If browser launch fails, build first. On Windows AIB.Browser.exe sits beside cli.cjs. Use open to establish an editor session. For a stale service, save your work, inspect status, stop it, then reopen.
